# 使用指南

在 `DailyBlog/content/posts/` 中维护 Markdown，可按 Obsidian 原笔记建立子文件夹。
附件放在 `DailyBlog/content/` 内；支持保留图片相对目录。旧附件目录 `DailyBlog/frontend/public/ReferencePicture/` 继续有效。
个人资料编辑 `DailyBlog/content/config/profile.json`。

支持的语法、两种版本和开发方式见根目录 `README.md`。GitHub Pages 配置见 `DEPLOY.md`。
每次更新笔记后推送源码，工作流会重新生成包含全部文章的 HTML。

风格按钮在 Aero 玻璃和荧光拼贴间切换；旁边的明暗按钮独立工作，选择会被记住。
两种版本均支持动效。系统“减少动态效果”设置可关闭装饰动画。
