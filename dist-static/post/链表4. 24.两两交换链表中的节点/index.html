24. 两两交换链表中的节点

给你一个链表，两两交换其中相邻的节点，并返回交换后链表的头节点。你必须在不修改节点内部的值的情况下完成本题（即，只能进行节点交换）。

示例 1：

输入： head = [1,2,3,4]
输出：[2,1,4,3]

示例 2：

输入： head = []
输出：[]

示例 3：

输入： head = [1]
输出： [1]

提示：

  • 链表中节点的数目在范围 [0, 100] 内
  • 0 <= Node.val <= 100

感觉链表操作其实都理解起来很简单的，不过都是写逻辑的过程中难免总是出现点小问题，
诸如什么死循环了，或者是越界错误了。不过那个后面会专门写一段做总结的。

总是涉及到要改指针指向的情况下，包括头节点也会被处理，很多时候题目给的情况都和我们学的教科书式的哑头节点不一样，题目总是喜欢用首元结点作为头节点。
处理很麻烦的时候，就想想给他提供一个哑节点吧，
哑节点可以利于我们无论什么情况下总能找回原来的那个链表的信息，
也可以有助于我们省去专门特殊处理掉head的情况，把head的特殊情形也化归成哑节点作为头节点是的情况。

但是这里除了双指针，两两作为单位交换，如果只有两个指针，一个零时指针的话会有一个问题，就是两两一组，作为在运行方向后面的那个节点，他总是要指向上一批节点，这样就会出现一个问题。就是找不到上一批节点。
一个解决方法就是两个指针不够用，那就再来一个指针，作为这两个指针每次运行的“观察者”。让它留在他们原来经过的上一个位置上。

CODE:

class Solution {  
public:  
    ListNode* swapPairs(ListNode* head) {  
        if (head == nullptr || (head != nullptr && head->next == nullptr)) {  
            return head;  
        }  
        // dummy 哑节点  
        // pre 观察者节点  
        // first 第一个节点  
        // second 第二个节点  
        auto* dummy = new ListNode(-1, head);  
        auto* pre = dummy;  
  
        while (pre->next != nullptr && pre->next->next != nullptr) {  
            auto* first = pre->next;  
            auto* second = pre->next->next;  
  
            auto* temp = second->next;  
  
            pre->next = second;  
            first->next = temp;  
            second->next = first;  
  
            pre = first;  
        }  
        return dummy->next;  // 做题是无所谓，但如果是实践一定要考虑dummy哇
    }
