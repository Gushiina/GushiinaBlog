数组1.二分查找法

📅 2026-04-28 📝 2286 字 #数组

#数组
易错点：  

做什么：在已经排序好的数组里寻找一个 target，判断 target 是否在数组里，在则返回下标，不断折半查找区间，最后到 mid 即为 target 的情况，若未找到则返回 -1。

  1. 第一点，while 循环 left 是＜还是小于等于 right  

  2. 第二点，假设 nums[mid] > target，说明 target 是在当前的区间左半边，要更新的是右区间端点。此时 right 应该是等于 mid 还是 mid-1？就是更新区间后究竟是加还是减还是等于  

  3. 第三点，更新 mid 下标时的整数溢出问题。

循环的不变量：  

对区间搜索之前，对区间的定义要明确，这个区间是左闭右闭，还是左闭右开。  

区间的定义将会影响我们写代码对边界条件的处理。

二分查找：两种区间写法及边界更新规则

1. 左闭右闭区间 [left, right]

  • 含义：搜索范围包含 left 和 right 指向的元素。

  • 循环条件：while (left <= right)

  • 中间点计算：mid = left + (right - left) / 2

边界更新规则

比较结果 更新方式 原因
target < nums[mid] right = mid - 1 mid 及右侧都大于 target，排除 mid，新的右边界为 mid-1
target > nums[mid] left = mid + 1 mid 及左侧都小于 target，排除 mid，新的左边界为 mid+1
target == nums[mid] return mid 找到目标

为什么必须 +1 或 -1？

因为 mid 已经检查过且不是目标，闭区间必须彻底排除 mid，否则可能死循环或重复检查。

代码模板


int search(vector<int>& nums, int target) {

    int left = 0, right = nums.size() - 1;

    while (left <= right) {

        int mid = left + (right - left) / 2;

        if (target < nums[mid])

            right = mid - 1;

        else if (target > nums[mid])

            left = mid + 1;

        else

            return mid;
    }

    return -1;

}

左闭右开区间 [left, right)

  • 含义：搜索范围包含 left，不包含 right。

  • 循环条件：while (left < right)

  • 中间点计算：mid = left + (right - left) / 2

边界更新规则

比较结果 更新方式 原因
target < nums[mid] right = mid 新区间 [left, mid)，右开自动排除mid
target > nums[mid] left = mid + 1 跳过 mid，新区间从 mid+1 开始
target == nums[mid] return mid 找到目标

代码模板


int search(vector<int>& nums, int target) {

    int left = 0, right = nums.size();

    while (left < right) {

        int mid = left + (right - left) / 2;

        if (target < nums[mid])

            right = mid;

        else if (target > nums[mid])

            left = mid + 1;

        else

            return mid;

    }

    return -1;

}
