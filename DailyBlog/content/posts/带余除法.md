#求余
# 整部 / 散部 余数模型

## 1. 基本设定

设：

- `m`：一个整体包含多少份，也就是“每整部有多少份”
- `n`：当前总共有多少份
- `k` / `full`：完整整部的个数
- `b` / `rem`：剩下散部的份数

则：

n = k * m + b

总份数 = 完整整部个数 * 每整部份数 + 散部份数

full = n // m     # 完整整部个数
rem  = n % m      # 散部份数

0 <= rem < m

m     每整部有多少份，叫“整部大小”
full  完整整部个数
rem   散部份数

不要直接把 `m` 叫成 `full`，否则容易和“整部个数 full”混淆。

---

## 2. 从“个数”角度

已知总共有 `n` 份，每整部 `m` 份：


full = n // m
rem  = n % m

含义：

full = n // m

表示这 `n` 份里面能凑出多少个完整整部。

rem = n % m

表示凑完整部后，还剩多少份散部。

并且：

n = full * m + rem

例子：

text

m = 5, n = 17
full = 17 // 5 = 3
rem  = 17 % 5  = 2

表示：

text

17 份 = 3 个完整整部 + 2 份散部

---

## 3. 从“序号”角度

这里的 `n` 表示“第 n 份”，为了避免混淆，也可以写成“第 i 份”。

设：

- `i`：第 i 份，序号从 1 开始
- `m`：每整部有 m 份

求第 `i` 份在哪里：

所在整部序号 = (i - 1) // m + 1
部内序号     = (i - 1) % m + 1

可以命名为：

part = (i - 1) // m + 1   # 第 i 份在第几部
pos  = (i - 1) % m + 1    # 第 i 份在该部内是第几份

解释：

i - 1

表示“第 i 份前面一共有多少份”。

(i - 1) // m

表示“第 i 份前面完整跨过了多少个整部”，再加 `1` 就是当前所在整部的序号。

(i - 1) % m

表示“第 i 份在当前这一部里，前面已经有几份”，再加 `1` 就是它在部内的序号。

---

## 4. 序号角度例子

每整部 `m = 5` 份，问第 `i = 17` 份在哪里：

part = (17 - 1) // 5 + 1
     = 16 // 5 + 1
     = 3 + 1
     = 4


pos = (17 - 1) % 5 + 1
    = 16 % 5 + 1
    = 1 + 1
    = 2

所以：
第 17 份 = 第 4 部的第 2 份


## 反向公式

如果已知第 `part` 部的第 `pos` 份，求总序号 `i`：

i = (part - 1) * m + pos

例子：
m = 5
第 4 部第 2 份
i = (4 - 1) * 5 + 2 = 3 * 5 + 2 = 17
