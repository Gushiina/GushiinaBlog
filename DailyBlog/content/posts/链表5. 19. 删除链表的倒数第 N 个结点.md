#链表 #双指针
[19. 删除链表的倒数第 N 个结点](https://leetcode.cn/problems/remove-nth-node-from-end-of-list/)


给你一个链表，删除链表的倒数第 `n` 个结点，并且返回链表的头结点。

**示例 1：**

![](https://assets.leetcode.com/uploads/2020/10/03/remove_ex1.jpg)

**输入：** head = `[1,2,3,4,5], n = 2`
**输出：** `[1,2,3,5]`

**示例 2：**

**输入：** head = `[1], n = 1`
**输出：** `[]`

**示例 3：**

**输入：** head = `[1,2], n = 1`
**输出：** `[1]`

**提示：**

- 链表中结点的数目为 `sz`
- `1 <= sz <= 30`
- `0 <= Node.val <= 100`
- `1 <= n <= sz`

---

## 与数组的对比
链表没有下标和索引，也不知道长度，一切的一切都不可知。遍历唯一可以清楚的，就是什么时候走向尽头 `（p==null）`。
## 一种直接的做法
1. 先让一个指针跑遍这个链表，算出长度 `length`。
2. 计算出 `length` 的差，知道是倒数第几个，就相当于知道顺数第几个。
3. 再跑一趟，让一个计数器计数，移动了几次。
**不过如果这个题目如果只允许你一趟出结果呢？**
## 植树问题模型
这里有一个叫做 **植树问题** 的模型，不过我大学生了都还总是搞错这个小学问题。
其实这里有一个数学关系，那就是这个倒数第几个 `N`。
### 举例
如果我们是说长度 `L` 为 4，倒数第 2 个和最后一个节点差几步？之间的长度是多少呢？
`[0] -> [1] ->  [2]  -> [3] -> null` 

- 倒数第 2 个，就是 `2`，实际上是 `L - N = 2`。
- 倒数第 `N` 个，就是顺数的第 `L - N + 1`，而实际的下标位置就是 `L - N`。
容易弄混的总是顺数第几个，和实际的下标，因为第几个总是从 1 开始数的。不过倒数就没那么多问题，因为我们很少会说“倒数几个”从 0 开始数。
## 快慢指针思路
一个指针 `p`，如果先走了 `N` 步，也就是走到了 `NULL`（对应了 `while` 的结束）。  
此时此刻，这个 `p` 的位置相当于 0，倒数第 `N` 个，也就是实际上差了几个。
例如这里 `p` 已经在 `null` 了：  
`index-p = N+1 = 5`（在外面了）。  
倒数第 `L` 个就是 `N-L+1` 个，他们始终中间会差几步？差了 `L` 步。
例如前面的例子，从 `2` 到 `NULL` 要走两步（指针移动一次就是走一步）。
那么我们只要让一对快慢指针，快指针先比慢指针走上 `L` 步（写一个会走上 `L` 步的循环）。  
那么当快指针走到尽头的时候，慢指针所指的位置就会变成我们要删除的那个对象。
### 删除元素的调整
不过这里因为要删除元素不是吗，既然是要删除元素，我们就要找到那个被删除元素的前一个对象，所以这里改了下 `while` 条件，让整体少走一步：  
`while(fast!=NULL)` 变成了 `while(fast->next!=NULL)`。
## 总结与建议
感觉植树问题还是要好好研究一下，争取脑子不用特别思考能直接弄对步数和位置的关系吧。
其实实在不行就不要装作太倔强，先拿笔来画一下特殊例子，刚开始学习多画几下总能争取做对的。

### 代码实现

```C++
class Solution {  
public:  
    ListNode* removeNthFromEnd(ListNode* head, int n) {  
        if (n > 30 || n <= 0) {  
            return head;  
        }  
        auto* dummy = new ListNode(-1, head); // 哨兵  
        auto* fast = dummy;                    // 快  
        auto* slow = dummy;                    // 慢 指向要删除的前一个对象  
        for (int i = 0; i < n; i++) {  
            if (fast->next != nullptr) {  
                fast = fast->next;  
            } else if (i != n - 1 && fast->next == nullptr) {  
                return head;  
                // 如果fast不是刚好到最后一个循环就将到尽头时  
                // 就就说明要删除的对象不存在  
            }  
        }  
        // 确定了快慢之间的步 长后进行整体式的移动  
        while (fast->next != nullptr) {  
            fast = fast->next;  
            slow = slow->next;  
        }  
        // 确定位置后开始执行操作  
        auto* temp = slow->next;  
        slow ->next = temp->next;  
        delete(temp);  
        auto* res = dummy->next;  
        delete(dummy);  
        return res;  
    }  
};
```
