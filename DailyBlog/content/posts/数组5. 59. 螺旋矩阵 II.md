#数组 #双指针 #滑动窗口
题干：
给你一个正整数 `n` ，生成一个包含 `1` 到 `n2` 所有元素，且元素按顺时针顺序螺旋排列的 `n x n` 正方形矩阵 `matrix` 。

**示例 1：**

![|240|240x240](https://assets.leetcode.com/uploads/2020/11/13/spiraln.jpg)

**输入：**`n = 3`
**输出：** `[[1,2,3],[8,9,4],[7,6,5]]`

**示例 2：**

**输入：** `n = 1`
**输出：** `[[1]]`

**提示：**

- `1 <= n <= 20`

---

这是一道模拟题，去模拟这个实际的下标跑动情况，然后根据情况收缩边界。
这也是我唯一迄今为止除了二分查找唯一一道凭借自己就做出来的的题目。

---

**关键点**：循环不变量
- 这里的循环不变量指的是边界的处理法则。
- 我们的区间是一个左闭右闭，左闭右开区间，或者说二维的区域开闭。这会决定我们的循环的初值，条件还有趋势的决定。以及哪些步骤应该在哪个区间进行处理。
- 为了一般为了符合自己的直觉，我这里选择了闭合区域。

**初版答案**：
```C++
class Solution {  
public:  
    vector<vector<int>> generateMatrix(int n) {  
        //  闭区域  
        int top = 0;  
        int left = 0;  
        int bottom = n - 1;  
        int right = n - 1;  
  
        int dir = 0; // 记录方向状态 0 右 1下 2左 3上  
  
        // 用于控制的坐标  
        int x = 0;  
        int y = 0;  
  
        vector<vector<int>> mat(n, vector<int>(n));  
  
        for (int i = 1; i <= n * n; i++) {  
            mat[y][x] = i;  
  
            if (dir == 0 && x == right) {  
                right--;  
                dir = 1;  
            }  
            if (dir == 1 && y == bottom) {  
                bottom--;  
                dir = 2;  
            }  
            if (dir == 2 && x == left) {  
                left++;  
                dir = 3;  
            }  
            if (dir == 3 && y == top + 1) {  
                top++;  
                dir = 0;  
            }  
  
            if (dir == 0) {  
                x++;  
            }  
            if (dir == 1) {  
                y++;  
            }  
            if (dir == 2) {  
                x--;  
            }  
            if (dir == 3) {  
                y--;  
            }  
        }  
  
        return mat;  
    }  
};
```

if控制大神，依旧秉持我们先斩后奏的原则，先跑后复盘。
于是你会发现，其实if语句对应的就是具体的处理情况，简化if就是把这些符号处理成一些具有含义的一个抽象。让它具有一个更加和谐统一的性质。
感觉就像实验然后处理数据归纳出公式一样。
不过试图抽象之后发现其实抽象与否看上去的复杂程度其实几乎一致就是了。只是感觉更加的模块化了。

**抽象后答案**：
```C++
class Solution {  
public:  
    vector<vector<int>> generateMatrix(int n) {  
        // 声明矩阵  
        vector<vector<int>> mat(n, vector<int>(n));  
  
        //  闭区域  
        int top = 1; // 初始上边界一开始不是0  
        int left = 0;  
        int bottom = n - 1;  
        int right = n - 1;  
        // 记录方向状态  
        int dir = 0; // 0 右 1下 2左 3上  
        // 四向移动  
        struct Directon {  
            int dy = 0;  
            int dx = 0;  
        };  
        vector<Directon> dr = {{0, 1},   // 右  
                               {1, 0},   // 下  
                               {0, -1},  // 左  
                               {-1, 0}}; // 上  
  
        // 用于控制的坐标  
        int x = 0;  
        int y = 0;  
  
        // 填充  
        for (int i = 1; i <= n * n; i++) {  
            mat[y][x] = i;  
  
            // 按照原来的方向，预判下一个位置，先错后修正  
            int nx = x + dr[dir].dx;  
            int ny = y + dr[dir].dy;  
            // 碰撞检测逻辑定义  
            bool hitBoundary = false;  
            if (dir == 0 && nx > right) {  
                hitBoundary = true;  
            } else if (dir == 1 && ny > bottom) {  
                hitBoundary = true;  
            } else if (dir == 2 && nx < left) {  
                hitBoundary = true;  
            } else if (dir == 3 && ny < top) {  
                hitBoundary = true;  
            }  
            // 碰撞检测  
            if (hitBoundary) {  
                // 边界收缩  
                if (dir == 0)  
                    right--;  
                else if (dir == 1)  
                    bottom--;  
                else if (dir == 2)  
                    left++;  
                else if (dir == 3)  
                    top++;  
                // 改变方向  
                dir = (dir + 1) % 4;  
                // 修正方向  
                // 3. 重新计算新方向的下一步   
                nx = x + dr[dir].dx;  
                ny = y + dr[dir].dy;  
            }  
            x = nx;  
            y = ny;  
        }  
        return mat;  
    }  
};
```

诶，不过这个在AI指导下的抽象给我提供了一个新的关于模拟的思维。

**收获**：
- 模拟检验：保持原来的运动状态进行推演，如果越界就在这个基础上更改状态向一个正确的结果跳跃。也就是我先犯错后纠正。不需要一步到位，而是在犯错中积累经验。

**题干隐藏的信息 易错点**：
- 上区间初始并不是0，这就好像是贪吃蛇一样，我自己已经走过的地方不能再走 。


**总结**：
- 这并不是自己初遇模拟类型的题目了，因为自己寒假几乎都在写这类。
- 模拟题最关键的是确定状态，以及状态转移的规则。注重的是各种具体清楚的分支。
- 通过断点调试观察状态值的变化有助于快速了解到状态转移是在哪一步上出了问题。
- 先斩后奏的思维。预判思维。
- 边界收缩问题同样可以视作窗口的一个变体。
