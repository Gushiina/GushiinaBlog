题干：
[209. 长度最小的子数组](https://leetcode.cn/problems/minimum-size-subarray-sum/)
给定一个含有 `n` 个正整数的数组和一个正整数 `target` 。找出该数组中满足其总和大于等于 `target` 的长度最小的 子数组 `[numsl, numsl+1, ..., numsr-1, numsr]` ，并返回其长度。如果不存在符合条件的子数组，返回 `0` 。

**示例 1：**

**输入：** target = 7, nums = `[2,3,1,2,4,3]`
**输出：** 2
**解释：** 子数组 `[4,3]` 是该条件下的长度最小的子数组。

**示例 2：**

**输入：** target = 4, nums = `[1,4,4]`
**输出：** 1

**示例 3：**

**输入：** target = 11, nums = `[1,1,1,1,1,1,1,1]`
**输出：** 0

**提示：**

- `1 <= target <= 109`
- `1 <= nums.length <= 105`
- `1 <= nums[i] <= 104`

**进阶：**

- 如果你已经实现 `O(n)` 时间复杂度的解法, 请尝试设计一个 `O(n log(n))` 时间复杂度的解法。

## 滑动窗口法

**双指针的变体**：
- 同时用一个指针left和right就可以表示出某个区间的一个子区间，如果画成方格图就会觉得“窗口”这样的比喻很形象了。

要从`n^2`转变成`n`，也就意味着控制窗口的两个指针，left和right，有一个是循环移动的参量，而另一个就得是伺机而动的那种。谁来做比较好呢？

只要做一个假想实验就好了，如果for控制的是left在数组上逐个移动，那么要让right动起来，要达到形成区间，滚出不同长度的窗口，那么就需要再来一条循环控制语句控制right了。如此的话就变成了`O(n^2)`级别了，又变回去了。

所以这里必然是先固定住left在0，让right向右移动，此时此刻right就能模拟当窗口起点位于最左侧时的子区间情景。

可问题来了，这只有窗口的扩大，而没有窗口的内缩，**left要怎么动起来**就成了真正的问题。。。

区间总和的求法，肯定不可能是再写一条循环去累加，那只有的可能就是right在移动的同时进行累加，累加到什么时候将会出现一个结果？和大于等于目标时。我们就可以计算出一个窗口长度。

因为是求长度最小值，我们可以不妨让最初始的长度为一个大正数。(其实最好用int32的最大值)

*( 这里我的选择是十的九次方。。。  这个实在是太坑爹了，其实一开始我选的是1e5，结果他21个测试用例里面竟然真的有一个结果刚好加起来就等于1e5的，然后最后我退出的判断语句又是写的若这个长度还是1e5则返回0 结果那个测试例没能过)*

那么 当处于这样的状态时，我们就可以尝试“内缩”left了，首先，先从和中减去left所指的元素，然后再让left++。

*(其实很多时候说到 当... 什么的时候 我们自然语言的这种逻辑判断反而更趋向编程中的 while？)*

直到内缩至内部之和小于目标值，然后继续让right前进增大窗口。直到结束。

这个过程中left和right始终是向右侧移动的，无论是right还是left都不会回头，没有重复的处理已经处理过的结果，这个结果自然大致感受上就是`O(n)`级别的。

**CODE**：
```C++
class Solution {

public:

    int minSubArrayLen(int target, vector<int>& nums) {

        int len = nums.size();

        int sum = 0;

        int left = 0;

        int right = 0;

        int min_len = 1e9;

  

        for (right; right < len; right++) {

            sum += nums[right];

  

            while (sum >= target) {

                min_len = min(min_len, right - left + 1);

                sum -= nums[left];

                left++;

            }

        }

        if (min_len == 1e9) {

            min_len = 0;

        }

        return min_len;

    }

};
```
