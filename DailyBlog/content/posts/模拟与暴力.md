对于一些比赛或者没有更优对策，出于应试骗分角度的算法技巧，而暴力法就应该足够暴力

(文章是针对C/C++的算法竞赛，尤其是蓝桥杯，没有什么范式，属于C和C++混合风格。因为考试这种东西就是要什么邪招都要拿出来，只要能拿到分才是道理)

## 核心在于两个步骤：

1. 找出数据可能大致存在的范围 （预估计算量）  
2. 将题干转化为判断条件，暴力检验 输出结果

## 暴力的两个思考维度：

1. 正向模拟：我大概估计这个解的范围，然后去直接检验每个解是否符合约束的条件。第二个是模拟思维，模拟自己真的再经历发生一个事件，然后将符合条件的情况记录。(例如这里的求年龄问题)
2. 逆向检验：我已经明白了这个解在的一个空间，利用题目给的约束条件，去构造可能的解，然很判断这个解是否在那个空间里存在（例如这个文章后面的子序列日期问题）

## 暴力的关键

1. 要足够的简单粗暴
2. 无法确定范围的时候就加大数字力度，只要存的下，不超时就应该随便搞！

## 例题

### 年龄问题

原题

美国数学家维纳（N. Wiener）智力早熟，11 岁就上了大学。他曾在 1935～1936 年应邀来中国清华大学讲学。一次，他参加某个重要会议，年轻的脸孔引人注目。于是有人询问他的年龄，他回答说：

> “我年龄的立方是个 4 位数。我年龄的 4 次方是个 6 位数。这 10 个数字正好包含了从 0 到 9 这 10 个数字，每个都恰好出现 1 次。”

请你推算一下，他当时到底有多年轻。

### 分析

**① 找范围，估算计算量。**

令年龄为 $x$。题目直接告诉我：年龄的立方必须是四位数。因此

$$
1000\le x^3\le9999
$$

这就意味着 $x$ 至少为 10，最多为 21。其实不必先假设人的寿命上限是 120 岁，题目给出的数字条件已经更精确了。候选只剩下 **10～21，共 12 个整数**；验证起来几乎没有成本。

还有四次方的六位数约束：

$$
100000\le x^4\le999999
$$

我可以把这条约束放进检验环节，不必一口气用所有条件推导出最终范围。

**② 变成布尔条件，逐个验证。**

每个候选年龄需要同时满足三条判断：

1. 立方是四位数；
2. 四次方是六位数；
3. 两个数合起来的十个数字恰好是 `0～9` 各一次。

第三条表面复杂，但既然已经保证两个数分别是四位和六位，拼接后就刚好有十位。只要十个数字**互不相同**，便必然覆盖 `0～9`。因此可以用一个计数数组，或者把字符串放进 `set<char>` 检查元素个数。

###  实现

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    for (int age = 10; age <= 21; ++age) {
        long long cube = 1LL * age * age * age;
        long long fourth = cube * age;

        if (cube < 1000 || cube > 9999) continue;
        if (fourth < 100000 || fourth > 999999) continue;

        string digits = to_string(cube) + to_string(fourth);
        set<char> uniqueDigits(digits.begin(), digits.end());

        if (digits.size() == 10 && uniqueDigits.size() == 10)
            cout << age << '\n';
    }
}
```

>>这里用到了set去重，当然也可以构造数组flag标记计数，都是可以的选择，取决于什么情景而已，如果是服务于竞赛出答案，那就什么C工具C++工具全都用上，如果是服务于考研代码题，那就老老实实用C的风格去模拟。

### 年龄问题2

小明带两个妹妹参加元宵灯会。别人问他们多大了，他们调皮地说：

> “我们俩的年龄之积是年龄之和的 6 倍。”

小明又补充说：

> “她们可不是双胞胎，年龄差肯定也不超过 8 岁啊。”

请你写出：**小明的较小的妹妹的年龄**。

### 分析

**① 找范围，估算计算量。**

设较小妹妹为 $a$ 岁，较大妹妹为 $b$ 岁。因为不是双胞胎，直接限定 $1\le a<b$，既符合题意，又不必对 `(a,b)` 与 `(b,a)` 重复计数。

年龄暂时看不出明确的上界，我可以先从关系式入手：

$$
ab=6(a+b)
$$

整理得

$$
(a-6)(b-6)=36
$$

这说明候选绝不是无穷多个：对于整数年龄，$a-6$ 和 $b-6$ 是 36 的正因子。也就是说，我甚至只需枚举一组有限的约数。

**这样的分析确实很严谨，但是这里就很不暴力了，为了答案可以不择手段！因为我们知道人类的岁数几乎不会超越100 120，如果出不了答案害怕，那就把这个数字开到1000 甚至 10000。计算机就是为了这个东西服务的，不管黑猫白猫，只要抓到耗子就是好猫，暴力法就应该足够暴力**

**② 变成布尔条件，逐个验证。**

```cpp
a * b == 6 * (a + b)  // 年龄乘积 = 年龄和的 6 倍
b - a <= 8             // 年龄差不超过 8
b > a                  // 不同龄，并且 a 是较小年龄
```

这就是题干最核心的数学内容。其余部分只是枚举候选。

### C++ 实现

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    for (int a = 1; a <= 42; ++a) {//这里当然可以是100 甚至1000
        for (int b = a + 1; b <= 42; ++b) {
            if (a * b == 6 * (a + b) && b - a <= 8)
                cout << a << '\n';
        }
    }
}
```


### 门牌制作

小蓝要为一条街的住户制作门牌号。这条街一共有 2020 位住户，门牌号从 1 到 2020 编号。小蓝制作门牌的方法是先制作 0 到 9 这几个数字字符，最后根据需要将字符粘贴到门牌上。

例如门牌 1017 需要依次粘贴字符 1、0、1、7，即需要 1 个字符 0、2 个字符 1、1 个字符 7。

请问要制作所有的 1 到 2020 号门牌，总共需要多少个**字符 2**？

### 分析

**① 找范围，估算计算量。**

编号范围在题目中明确给出：**1～2020**。最多需要检查 2020 个数，每个数不超过四位，工作量不到一万次数位检查，非常适合直接模拟。

**② 变成布尔条件，逐个验证。**

这里枚举的是编号，而判断发生在编号的**每一位数字**上。题干说需要多少字符 `2`，也就是说只要当前数位等于 2，答案就加一：

```cpp
x % 10 == 2
```

`x % 10` 取最后一位，`x /= 10` 去掉最后一位；不断重复，就能完整检查所有数位。

### C++ 实现

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int ans = 0;
    for (int number = 1; number <= 2020; ++number) {
        int x = number;
        while (x > 0) {
            if (x % 10 == 2) ++ans;
            x /= 10;
        }
    }
    cout << ans << '\n';  // 624
}
```

**结果：624。


### 国庆节与星期

计算第xxxx年的国庆节是星期几

### 分析

**① 找范围，估算计算量。**

年份从 1949 到 2012，只有

$$
2012-1949+1=64
$$

个候选。每年只计算一次星期，再做一次比较，计算量可以忽略。

最粗暴的方法，就是打表格，然很算闰年，手动一点一点吧1949年到题目的年份2012年全部都算一遍。

但是C标准库其实很早就有时间戳工具库，他的头文件叫`time.h(c风格头)或者ctime(cpp风格头)`

之后会单写一个文章讲。

### `<ctime>暴力`

`tm` 结构体中，`tm_year` 表示年份减 1900，`tm_mon` 从 0 开始计月，`tm_wday` 是星期（**0=星期日**）。我之前曾写成 `tm_wady`，需要纠正。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    const int target = 0; // 示例：星期日；实际应按原题修改
    int ans = 0;

    for (int year = 1949; year <= 2012; ++year) {
        tm t = {};
        t.tm_year = year - 1900;
        t.tm_mon = 9;    // 十月
        t.tm_mday = 1;
        t.tm_hour = 12;
        t.tm_isdst = -1;
        mktime(&t);
        if (t.tm_wday == target) ++ans;
    }
    cout << ans << '\n';
}
```

不过需要记住：**`mktime` 使用本地时区和系统的日期转换规则；除此之外会遇到时区或夏令时问题**。日期范围可表示性也与平台有关。竞赛里我更倾向于不依赖环境的数学方法。 不过mktime可以把非法日期自动更新为合法日期，实在是太棒了。

### 方案二：基姆拉尔森公式

这个是一个补充，并不算暴力，之后会单开一个专门讲日期的板块来记录。

$$
w=\left(d+2m+\left\lfloor\frac{3(m+1)}5\right\rfloor+y+\left\lfloor\frac y4\right\rfloor-\left\lfloor\frac y{100}\right\rfloor+\left\lfloor\frac y{400}\right\rfloor+1\right)\bmod7
$$

其中 $y,m,d$ 是年、月、日；**一月、二月需要改作上一年的 13 月、14 月**。在这个版本中，返回值 `0～6` 对应星期日～星期六。

```cpp
int weekday(int year, int month, int day) {
    if (month <= 2) {
        month += 12;
        --year;
    }
    int w = day + 2 * month + 3 * (month + 1) / 5
          + year + year / 4 - year / 100 + year / 400 + 1;
    return (w % 7 + 7) % 7;
}
```

例如 `weekday(2023,10,1)` 应为 `0`（星期日），可以用来校验公式与星期编号是否匹配。

### 日期统计（据提供的截图整理）

小蓝现在有一个长度为 100 的数组，数组中的每个元素的值都在 0 到 9 的范围之内。数组中的元素从左至右如下所示：

```text
5 6 8 6 9 1 6 1 2 4 9 1 9 8 2 3 6 4 7 7 5 9 5 0 3 8 7 5 8 1 5 8 6 1 8 3 0 3 7 9 2
7 0 5 8 8 5 7 0 9 9 1 9 4 4 6 8 6 3 3 8 5 1 6 3 4 6 7 0 7 8 2 7 6 8 9 5 6 5 6 1 4
0 1 0 0 9 4 8 0 9 1 2 8 5 0 2 5 3 3
```

现在他想要从这个数组中寻找一些满足以下条件的子序列：

1. 子序列的长度为 8；
2. 这个子序列可以按照下标顺序组成一个 `yyyymmdd` 格式的日期，并且要求这个日期是 2023 年中的某一天的日期，例如 `20230902`、`20231223`。`yyyy` 表示年份，`mm` 表示月份，`dd` 表示天数，当月份或者天数的长度只有一位时需要一个前导零补充。

请你帮小蓝计算下按上述条件一共能找到多少个**不同的** 2023 年的日期。对于相同的日期你只需要统计一次即可。

> [!warning] 原题术语校核
> 截图使用“子序列”而非“连续子数组”，因此**不应直接假设 8 个数字必须相邻**。下文原先使用的长度为 8 的滑动窗口仅适用于“连续”版本，不是此原题的正确解法。

### 分析

如果正向思考，想着从这里面寻找出子序列，一点一点再拼凑出来，看看有没有2023xxxx的串。
那就真的要被串飞了，因为这可能涉及到了深度优先搜索DFS和剪枝，而我们要的是暴力。所以我们不是从题目中推出来，我们可以知道，子序列是2023xxxx的串，一定是被包含在所有的2023xxxx这种格式的日期里头，所以我们把所有日期全部试一遍，反过来在题目给的空间里寻找出有没有我想的这个，如果有那就是存在，没有就是不存在。这才是真正的**暴力**

**暴力枚举之前，思考枚举什么也很关键**

**① 找范围，估算计算量。**

枚举这 365 个日期，逐个判断是否能作为子序列从数组中取出。

每个日期最多扫描 100 个数字，总共约 $365\times100=36500$ 次比较，完全可行。

**② 变成条件，逐个验证。**

对每个 `yyyymmdd` 日期字符串，我只需要判断：**它的八位数字是否能够按原数组的先后顺序依次匹配到？**

```cpp
isSubsequence(a, dateString)
```

匹配时只向前扫描数组，遇到与当前目标位相等的数，就把目标位置向后移动一位。匹配完八位返回 `true`，否则为 `false`。

### C 实现

```cpp
#include <bits/stdc++.h>
using namespace std;

bool isSubsequence(const vector<int>& a, const string& target) {
    int j = 0;
    for (int digit : a) {
        if (j < (int)target.size() && digit == target[j] - '0')
            ++j;
    }
    return j == (int)target.size();
}

int main() {
    vector<int> a(100);
    for (int& x : a) cin >> x;

    int days[] = {0,31,28,31,30,31,30,31,31,30,31,30,31};
    int ans = 0;

    for (int month = 1; month <= 12; ++month) {
        for (int day = 1; day <= days[month]; ++day) {
            char date[9];
            snprintf(date, sizeof(date), "2023%02d%02d", month, day);
            if (isSubsequence(a, date)) ++ans;
        }
    }
    cout << ans << '\n';
}
```

因为我按每个合法日期枚举了一次，**相同日期天然不会重复统计**，甚至不需要使用 `set` 去重。

这里也顺带纠正一个容易混淆的点：如果把“子序列”误读成“连续的八位数字”，就会写出错误的滑动窗口方案。**先弄清楚题目允许怎样选择候选，再决定枚举方式。
