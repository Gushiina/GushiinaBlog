#数组 #双指针 
[977. 有序数组的平方](https://leetcode.cn/problems/squares-of-a-sorted-array/)

---
给你一个按 **非递减顺序** 排序的整数数组 `nums`，返回 **每个数字的平方** 组成的新数组，要求也按 **非递减顺序** 排序。

**示例 1：**

- **输入：** nums = $[-4,-1,0,3,10]$
- **输出：**$[0,1,9,16,100]$
- **解释：** 平方后，数组变为 $[16,1,0,9,100]$
- 排序后，数组变为 $[0,1,9,16,100]$

**示例 2：**

- **输入：** nums =   $[-7,-3,2,3,11]$
- **输出：**$[4,9,9,49,121]$

**提示：**

- `1 <= nums.length <= 104`
- `-104 <= nums[i] <= 104`
- `nums` 已按 **非递减顺序** 排序

**进阶：**

- 请你设计时间复杂度为 `O(n)` 的算法解决本问题

---

首先捕捉到的要素是：排序，新数组，非递减顺序，还有`O(n)`的复杂度。

**非递减顺序**：
- 就是不严格的单调递增顺序，升序的同时存在相邻元素相等。
**新数组**：
- 这题没有空间复杂度的限制，这句话也告诉了你最后是可以自己建一个数组返回，说明了是可以开辟空间的。
**`O(n)`**：
- 这里已经暗示了只能循环一次，首先传统的排序算法本身最坏的情况下基本都排除了。这个进阶的复杂度的情况，空间换时间，还有双指针就很有可能性了。

当然凭我自己还是没想到这个双指针是怎么个双指针法，，，嘛功力暂时还不够嘛。

---

暴力法。最直白的就是全部算一次平方，然后再排一次序。例如快排$O(nlogn)$，不过这样就没多大意义了。

---

**双指针法**：
- 破局点在于这个加粗的 **非递减顺序** 上 ，原来的元素是有特征的，他们是升序排放的，而对于这种升序排放的的数字平方之后就会出现一个特点，极大值总是出现在首尾两侧，我们就是要从这个极大值可能出现的位置去切入，在数组的左右两侧同时进展工作，也就是一个左指针和一个右指针。
- *这变相告诉我们解题除了关注传统的套路的同时还要善于去观察提供的原始数据具有什么特点，这都是对解题方式选择的暗示*
- 左右指针指向首尾两侧，计算两侧的平方，然后比较大小，较大的那一个数存入新数组的尾侧，直到左右两侧相遇了。
- 所以归结循环的三要素：
	- 初值是`left = 0,right = end`，
	- 循环条件是`left <= right`，
	- 趋势是`left++`或者`right--`
- 这里条件要取等，是为了避免同时指向一个数字的时候，不取等条件的话就会漏掉一个元素。
---

**CODE**：
- 为了更加的灵活，所以还是选择了while循环

``` C++
class Solution {

public:

    vector<int> sortedSquares(vector<int>& nums) {

        int len = nums.size();

        // 初始化要确定大小，否则下标的访问实际上是会存在越界风险的

        vector<int> res(len);

  

        int left = 0;

        int right = len - 1;

        int index = len - 1;

        while (left <= right) {

            int square_l = nums[left] * nums[left];

            int square_r = nums[right] * nums[right];

  

            if (square_l > square_r) {

                res[index] = square_l;

                left++;

            } else {

                res[index] = square_r;

                right--;

            }

  

            index--;

        }

        return res;

    }

};
```
