给你两个单链表的头节点 `headA` 和 `headB` ，请你找出并返回两个单链表相交的起始节点。如果两个链表没有交点，返回 `null` 。

题目数据 **保证** 整个链式结构中不存在环。

## 初探

这一道题和上一道题是有着一定异曲同工之妙的，“时间复杂度 `O(n)` 、仅用 `O(1)` 内存的解决方案”基本就和双指针基本脱不开的感觉了。

我们不妨来看一下这样的一个例子。
![[6. 面试题 02.07. 链表相交-1776738062971.png]]
再这样的情况下，AB双链的长度是一样长的，AB链上运动的指针分别是p和q，如果他们走到这两条链的交点的时候，是不是此时此刻p和q就会同时指向同一块地址？

稍作修改，那如果我们把上面的路径给去掉一个
![[6. 面试题 02.07. 链表相交-1776738301088.png]]
此时此刻，是不是当指针p已经指向那个点的时候，q却比p滞后了1步。
关键就在这个之后的1，他韵涵了什么样的数学关系?
A链比B链少一个元素，这正是A和B之间的长度差值。

有此我们可以想到的一个解法就是。
两个指针都开始跑，
![[6. 面试题 02.07. 链表相交-1776738489140.png]]
谁先到终点，就意味着他是短链，把它标记下来。
从第一个指针到了终点后，我们开始计数，直到第二个指针也到达终点。
我们就得到了这两者的长度差。
我们让p和q重新回到起点，让长链先跑这个长度差步，

![[6. 面试题 02.07. 链表相交-1776738605443.png]]
这样他们就属于同一起点了。然后再次出发，当他们的地址相同时，就意味着这个点是交点。
如果这里不存在交点，那么在平衡了长度差之后同事出发，他们也会同时都指向nullptr，也会想等退出。

## 再探

前面我们其实已经抓到了这样的一个核心，这个问题的解决是**补齐了两个链的长度差**以便两个指针能够走向同一个起点，最终同时到达交点。

我们可以在换一个思维起到这个**补**的效果。

那就是，假如说，
- p沿着A链跑完了整段长度为A，而交点(包括这个交点)之前的距离记作C。
- q沿着B链跑完了整段长度为B，而交点(包括这个交点)之前的距离记作D。

如果
- 把B交点之前(包括这个交点)的内容割下来，补在了A的后头。
- 把A交点之前(包括这个交点)的内容割下来，补在了B的后头。

此时
- p就要走A+D步
- q也要走B+C步

而A+D = B+C

不是吗？

因为交点后面那一段的长度是一样的，我只是补齐了我们之间到达终点的距离。

于是根据p和q之间的状态，我们就可以写出这样的代码：

```C++
class Solution {  
public:  
    ListNode* getIntersectionNode(ListNode* headA, ListNode* headB) {  
        if (headA == nullptr || headB == nullptr) {  
            return nullptr;  
        }  
  
        auto* p = headA;  
        auto* q = headB;  
  
        while (p != q) {  
            p = (p == nullptr) ? headB : p->next;  
            q = (q == nullptr) ? headA : q->next;  
        }  
  
        return p;  
    }  
};
```
当P走向尽头的时候，我们让P从B上重新开始跑，而当Q走向尽头的时候，我们让Q从A上重新开始跑，这样做也补齐了两条链之间的长度差。最后他们都会相遇。

但倘若这里不存在交点，那么他们在第一次的交换之后，也会最后分别走向nullptr，最后因为p和q相等跳出循环。
