#链表 #双指针
给你单链表的头节点 `head` ，请你反转链表，并返回反转后的链表。

**示例 1：**

![|542x222](https://assets.leetcode.com/uploads/2021/02/19/rev1ex1.jpg)

**输入：** head = `[1,2,3,4,5]`
**输出：**`[5,4,3,2,1]`

**示例 2：**

![](https://assets.leetcode.com/uploads/2021/02/19/rev1ex2.jpg)

**输入：** head = `[1,2]`
**输出：** `[2,1]`

**示例 3：**

**输入：** head = `[]`
**输出：** `[]`

**提示：**

- 链表中节点的数目范围是 `[0, 5000]`
- `-5000 <= Node.val <= 5000`

**进阶：** 链表可以选用迭代或递归方式完成反转。你能否用两种方法解决这道题？

---

**迭代法**：
使用了双指针
指针prev总是只想我们渴望成为后继的节点
而curr指向反转环节成为那个后继节点前驱的节点
我们要始终能够回溯到旧链的位置上，所以要用一个零时指针temp存储原方向链表的节点

```C++
/**  
 * Definition for singly-linked list.  
 * struct ListNode {  
 *     int val;  
 *     ListNode *next;  
 *     ListNode() : val(0), next(nullptr) {}  
 *     ListNode(int x) : val(x), next(nullptr) {}  
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}  
 * };  
 */  
class Solution {  
public:  
    ListNode* reverseList(ListNode* head) {  
        if (head == nullptr) {  
            return head;  
        }  
        // prev 始终是要指向一个要成为后继的节点  
        // curr 则是指向这次要操作的节点  
        // temp 存储原来的后继，这样我们才能继续找到这个 链表  
        ListNode* prev = nullptr;  
        ListNode* curr = head;  
        ListNode* temp = curr->next;  
        // 开始迭代  
        while(curr != nullptr){  
            temp = curr->next;  
            curr->next = prev;  
            prev = curr;  
            curr = temp;  
        }  
        return prev;  
    }  
};
```

**递归法**：

这种翻转顺序，翻转数字顺序等等，就可以运用到**栈**结构了。例如这里就可以存入。依次弹射。不过就要消耗额外的空间。实际上这里用到的栈是一个系统栈。(其实写一个手动栈压入在弹出也可以)

对于递归写法也是如此，递归写法实际上就是，对于一个n规模的问题，他可以被分解成一个n-1规模的子问题。

规模为n时，我们将n个节点的链表翻转后的结果后继为nullptr
规模为n-1是，我们将n-1个节点的链表反转后的结果，让他的后继为head
......
规模为1时，反转1个节点，让他的后继变成那个prev

于是我们就可以抽象处递归函数
F(cur,pre) 
于是有

（大概你可以理解成，边界就去思考最后一个处理的情况和最特殊的情况，而后面写的代码你就只思考最一般的情况）

```C++
class Solution {  
public:  
    ListNode* reverseList(ListNode* head) {  
        return recur(head,nullptr);  
    }  
private:  
    ListNode* recur(ListNode* curr,ListNode* prev) {  
        if(curr==nullptr){  
            return prev;  
        }  
        auto* res = recur(curr->next,curr);  
        curr->next = prev;  
        return res;  
    }  
};
```

不过最主要还是要掌握迭代法就是了。
