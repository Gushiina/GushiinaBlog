#求余

和差积累的模=先取模后和差 用于解决大数和差积的求余问题

(a + b) mod M = (((a mod M) + (b mod M)) mod M)
(a - b) mod M = (((a mod M) - (b mod M)) mod M)   // 数学 mod，结果自动非负
(a * b) mod M = (((a mod M) * (b mod M)) mod M)

## 减法防负

a-b可能得出负数的结果 而负数取模结果众说纷纭 不确定（看环境）
所以我们可以先转化回正数 因为

n ≡ a - b (mod m) 即 n = a - b + k * m
[[带余除法]]

故减法防负可以为 
n ≡ a - b (mod m) ≡ a - b + m (mod m)

即 
(a - b) % M的正确结果 = (a - b + M) % M
但他的先决条件是 a-b本身不溢出，
若ab都是大数则要写
((a % M) - (b % M) + M) % M

乘法中间结果 (a mod M)*(b mod M) 不能溢出，否则用 __int128 或快速乘
